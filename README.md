# Bryan Thomas — Portfolio Website

Personal portfolio site for Bryan Thomas, CS student at Kent State University seeking Summer 2026 internships in data analytics, data engineering, and software development.

**Live site:** https://accidentalspaceman.github.io/Portfolio-Website/

## About

Single-page portfolio built with vanilla HTML, CSS, and JavaScript. No frameworks or build tools — just one file you can open directly in a browser or deploy anywhere.

## Features

- Cyberpunk/dark theme with neon purple and cyan accents
- CRT scanline overlay effect
- Glitch animation on the hero heading
- Scroll-triggered fade-in animations via IntersectionObserver
- Cycling role text in the hero
- Fixed nav with backdrop blur
- Responsive layout (mobile-friendly)
- Resume download link

## Projects showcased

- **Killjoys App** — Android client management app for a tattoo studio (Kotlin, Jetpack Compose, Firebase)
- **Intel Sustainability Analysis** — SQL-based analysis across 150k+ device records (SQL, CTEs, data storytelling)
- **Grammy Website Performance Analysis** — Traffic and engagement analysis (Python, Pandas, Plotly)
- **AI Job Hunting Agent** — Automated job search and cover letter generator (Python, Anthropic API)
- **Crypto Inventory Scanner** — CLI tool to audit cryptographic algorithms in codebases for post-quantum readiness (Python, static analysis, CycloneDX, SARIF)
