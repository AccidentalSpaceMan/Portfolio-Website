Post-Quantum Key Exchange Lab

A local TLS 1.3 server and client that negotiate X25519MLKEM768 — the post-quantum hybrid Chrome and Cloudflare use — and prove it by decoding the handshake bytes (group 0x11EC, 1,216/1,120-byte key shares). Walks through ML-KEM-768 step by step and benchmarks it against X25519: 2,336 vs 64 bytes per exchange, under 0.5 ms of CPU.

Python TLS 1.3 ML-KEM Post-Quantum OpenSSL

Crypto Inventory Scanner

A CLI that finds the cryptography in Python, Java, JS/TS, Go and certificate/key files, grades 56 algorithms BROKEN / LEGACY / CURRENT, flags quantum-vulnerable ones, and writes a CycloneDX CBOM and SARIF for GitHub code scanning. 257 tests, release v0.9.0.

Python Static Analysis CBOM SARIF Security

Crypto Primitive Playground

A Python CLI demonstrating AES-256-GCM, SHA-384, Ed25519, and a hybrid X25519 + ML-KEM file encryption example. Hands-on proof that these primitives work before deploying them in production.
